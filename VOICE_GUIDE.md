# Voice guide: moved

This guide is now split into two parts:

- **[`VOICE_STYLE.md`](VOICE_STYLE.md)**: the voice itself, for any app: ElevenLabs settings, pace,
  pauses, emphasis, tone, background sound, other languages, code, quality checks, pitfalls, and a general prompt.
- **[`AUDIO_GUIDE.md`](AUDIO_GUIDE.md)**: what is specific to walking audio guides: tour structure,
  stops and directions, interactive "Find it" challenges, indoor tracks, map data, the GPS web page, and a guide prompt.

Tool: [`tools/tts_lecture.py`](tools/tts_lecture.py) generates MP3s in this voice from a JSON of texts.
